# تهيئة Student Agent — M189

هذه أدوات مسؤول المعمل. لا يدخل الطالب مفتاحًا أو IP أو بصمة شهادة، ولا تظهر له لوحة إعدادات في التشغيل العادي.

1. جهّز تطبيق المعلم واحفظ إعداد المعمل.
2. شغّل Prepare-Teacher-Windows.cmd أو Prepare-Teacher-Mac.command من أدوات المعلم. اختر عنوان المعلم على شبكة المعمل مرة واحدة. تُنشأ حزمة طلاب خاصة تتضمن lab-profile.json والمفتاح وبصمة الشهادة تلقائيًا.
3. ثبّت Student Agent M189 على أجهزة الطلاب (في ماك استخدم PKG). شغّل Setup-Student-Windows.cmd أو Setup-Student-Mac.command من الحزمة الخاصة **تحت حساب الطالب الذي سيستخدم الجهاز**، وليس حسابًا آخر، حتى تُحفظ DPAPI/Keychain للحساب الصحيح.
4. يمكن تجهيز Agent منتظر في الخلفية دون فتح نافذته أو إغلاقه. يعتمد المعلم هوية الجهاز من لوحة المعلم.

المفتاح الجديد من 3 إلى 8 أرقام. الحزمة الخاصة تحتوي مفتاح المعمل؛ انقلها عبر وسيط موثوق ولا ترفعها إلى GitHub أو المحادثة. الأدوات ترفض استبدال إعداد معلم أو مفتاح مختلف تلقائيًا وتحافظ على هوية كل جهاز مستقلة.

أذونات macOS للشاشة وإمكانية الوصول تُجهّأ محليًا أو بواسطة MDM، ولا تتجاوزها الأدوات. تبدأ خدمة المستخدم بعد تسجيل الدخول؛ ليست خدمة SYSTEM/Daemon للتحكم قبل شاشة الدخول. التشغيل المعتاد لا يعرض إعدادات، وتظهر نوافذ المعلم ومؤشرات الجلسة اللازمة فقط. لا تحذف الإعدادات أو Keychain عند تحديث البرنامج.
