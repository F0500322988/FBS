# FBS Classroom — M182 — تعديلات تجربة معمل Mac

استجابةً لتجربة المستخدم الفعلية للنسخة الظاهرة M179:

- شاشة المعلم تظهر تلقائيًا للطالب بملء الشاشة عند بدء المعلم البث، دون قبول أو رفض لكل جلسة. النافذة دون عنوان أو زر إغلاق أثناء البث الحديث؛ ينهيها المعلم أو تنتهي تلقائيًا بفقد الصورة/الاتصال. لا يتجاوز ذلك اختصارات النظام أو Force Quit، ولا يلتقط شاشة الطالب تلقائيًا.
- صورة المعلم تملأ مساحة العرض المتاحة مع الحفاظ على نسبتها، دون قص محتوى الدرس. قد تبقى حواف سوداء عندما تختلف نسبة شاشتي المعلم والطالب. العرض متتابع بلا صوت كما في هذه النسخة؛ ليس فيديو عالي الإطارات.
- لوحة «طاقة الأجهزة» توفر سكون وإيقاف وإعادة تشغيل للأجهزة المتصلة والمعتمدة ذات الطالب M182. يؤكد المعلم قائمة المستلمين مرة واحدة، دون طلب قبول أو رفض على الطالب لكل أمر.
- «تشغيل / إيقاظ المحدد» يرسل Wake-on-LAN إلى عناوين Ethernet المحفوظة للأجهزة المعتمدة، حتى بعد اختفائها من قائمة المتصلين. يتعلم العنوان عند تشغيل الطالب M182 واعتماده وتثبيت عنوان المعلم وبصمته مرة واحدة.

## iMac وEthernet

فعّل «التنبيه للوصول إلى الشبكة» في إعدادات الطاقة بحسب إصدار macOS وطراز الجهاز. جرّب السكون والإيقاظ أولًا. لا نضمن تشغيل iMac مطفأ بالكامل بحزمة شبكة، خصوصًا Apple Silicon؛ يعتمد ذلك على دعم العتاد والطاقة. لإدارة معمل لا يدعم ذلك، استخدم السكون/الإيقاظ أو جدول بدء تشغيل يضبطه مسؤول الأجهزة محليًا. لا يوجد مستقبل برمجي يعمل على جهاز مطفأ تمامًا.

Mac يستخدم System Events لطلبات السكون والإيقاف وإعادة التشغيل. قد يحتاج إذن Automation مرة واحدة ضمن إعداد الجهاز من مسؤول المعمل؛ لا يتجاوز التطبيق إذن macOS أو يطلب كلمة مرور الطالب عبر الشبكة. Windows يستخدم طلبات النظام دون خيار إغلاق إجباري للتطبيقات. قد تمنع التطبيقات المفتوحة أو أذونات النظام إكمال العملية.

## ما تعنيه الحالة

«أُرسلت حزمة الإيقاظ» ليست تأكيد تشغيل. «استلم التطبيق الأمر» أو «أُرسل إلى النظام» ليست تأكيد إيقاف. انقطاع الشبكة ليس إثبات إطفاء. تتحقق النتيجة بمشاهدة الجهاز وعودة اتصاله. طلبات الطاقة محددة الهوية والمستلم والمفتاح والمهلة، ولا تُعاد تلقائيًا بعد الاستلام.

اختبارات النقل لا تقفل أو تطفئ جهاز الاختبار لتوليد نجاح مصطنع. اختبار الأجهزة الحقيقية المعدّلة ما زال يحتاج تشغيل M182 في المعمل. أذونات تسجيل شاشة المعلم وأذونات Accessibility للتحكم بالطالب تبقى متطلبات نظام مستقلة. إصدار Windows غير موقّع وMac بتوقيع Ad-hoc دون Developer ID/Notarization.
