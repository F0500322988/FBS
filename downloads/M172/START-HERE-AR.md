# M172 — تحديث لوحة المعلم

هذه مرحلة تحسين واجهة وتشديد عرض الصور؛ لا تعني اكتمال برنامج إدارة المعمل.

## التغييرات

- لوحة عربية بألوان زرقاء وكحلية وفق مرجع التصميم، مع عرض بطاقات أو قائمة والتحكم بحجم البطاقات.
- اسم المعمل وأعداد الأجهزة ووضع الاتصال مأخوذة من الخادم؛ لا تعرض الواجهة صور سطح مكتب مصطنعة على أنها شاشات فعلية.
- حالات واضحة عند عدم وجود أجهزة أو عدم مطابقة البحث أو تعذر الاتصال.
- صفحات البث والقفل والملفات والرسائل والتحكم وإدارة المعمل توضح أنها غير متاحة، ولا تعيد عرض شبكة الأجهزة وكأن الوظيفة تعمل.
- إزالة آخر صور الشاشات عند تعذر جلب الصور أو فشل الخادم. تُعرض فقط صور JPEG الحديثة لأجهزة متصلة ومعتمدة، ويمسح الحوار المكبر صورته عند توقف التحديث.
- منع تداخل تحديثات الحالة، ومهلة خمسة ثوانٍ لكل طلب لتجنب بقاء التحديث عالقًا.

## الاختبارات

نجح تشغيل 1436 اختبار JavaScript، دون فشل أو تخطٍّ. نجح اختبار قبول الواجهة في Chromium باستخدام بيانات API محاكية: الحالة الخالية، البحث، القائمة، الحالات الحية والمنقطعة، رفض صور غير المعتمدين والصور القديمة، فتح التكبير بلوحة المفاتيح، إزالة الصور عند HTTP 503، إخفاء الوظائف الناقصة، التعافي، ملاءمة عرض 390 بكسل، وعدم وجود أخطاء JavaScript غير معالجة.

اختبار المتصفح: `FBS_BROWSER_EXECUTABLE=/usr/bin/chromium node tests/browser/m172-workspace.cjs` في هذه البيئة. عند استخدام Playwright Chromium المثبت بالطريقة المعتادة يمكن حذف المتغير. لقطة الواجهة المرفقة تستخدم بيانات اختبار وليست إثبات اتصال جهاز Windows حقيقي.

لم يتغير كود .NET في هذه المرحلة ولم تُعد فحوصه. آخر فحوصه السابقة على Linux كانت 48 للإعداد وTLS و80 NativeGate. لا تعادل تشغيل Windows أو DPAPI.

## المثبّتان

يُعاد تغليف ملفات Windows x64 السابقة مع أصول واجهة M172 الجديدة. يبقى إصدار التطبيق الأصلي المضمّن `0.170.0-preview`؛ M172 رقم مرحلة الواجهة والتغليف. يوجد مثبّت معلم ومثبّت طالب منفصلان. لا تغيّر المرحلة محرك الطالب أو تضيف ميزات القفل والبث والتحكم والرسائل.

لإعادة إنتاج الحزم: `FBS_RELEASE_STAGE=M172 bash windows/nsis/build-linux.sh <stage-root> <fresh-output>`؛ تحتاج حمولتي Teacher وStudent الموثقتين مع Runtime، وتتحقق الأداة من كل ملف بعد الاستخراج. النتائج والأحجام والبصمات في تقرير M172 المرفق عند التسليم.

التثبيت: اتبع دليل M171. أغلق التطبيق وأزل النسخة التجريبية السابقة قبل تثبيت الجديدة في المسار نفسه؛ إعدادات المستخدم تبقى محفوظة. المثبّتان غير موقّعين. لم يُنفذ التثبيت أو الإزالة أو تشغيل الواجهات على Windows فعلي، ولا اختبار جهازين في شبكة فعلية. نسخة macOS ومطابقة التصميم الكامل والوظائف الناقصة ما زالت أعمالًا لاحقة.

## نتيجة بناء M172

اكتمل تشغيل سكربت البناء والتحقق بالكامل: بُني المثبّتان واستُخرجا وطابقت بصمات SHA256 والأحجام لجميع الملفات الـ83 (42 للمعلم و41 للطالب)، دون ملفات حمولة غير متوقعة. هذا تحقق من الحزم وليس اختبار تثبيت Windows.
