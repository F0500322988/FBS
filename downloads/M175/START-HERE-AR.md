# M175 — نسخة macOS وiMac — Intel وApple Silicon

أُضيف مصدر تطبيقَي المعلم والطالب الأصليين باستخدام Swift وAppKit، مع مسار بناء Universal لمعالجَي Intel وApple Silicon. الحد الأدنى المستهدف macOS13 Ventura. ليس كل جهاز iMac قديم قادرًا على تشغيل macOS13؛ نوع المعالج وحده لا يحدد التوافق.

## ما أضيف

- تطبيق مستقل للمعلم يشغّل خادم المعمل ويفتح لوحة المعلم في المتصفح، مع عرض IP والمنفذ وبصمة الشهادة.
- تطبيق مستقل للطالب، باتصال يدوي وبصمة المعلم أو اكتشاف تلقائي اختياري، واسم جهاز قابل للتعيين.
- حفظ إعدادات الاتصال ومفتاح المعمل وكلمة مرور المعلم في Keychain الخاص بالمستخدم؛ لا تمرر الأسرار عبر معاملات سطر الأوامر.
- رسائل نصية مع تأكيد قراءة صريح، ونافذة عرض لقطات شاشة المعلم. يمكن للطالب إغلاق العرض.
- فتح صفحة مشاركة شاشة الطالب بموافقته، واختيار شاشة المعلم من لوحة المتصفح. أذونات تسجيل الشاشة تخص المتصفح المستخدم وتخضع لإعدادات macOS؛ لا تُتجاوز تلقائيًا.
- Node22.23.4 مضمن للمعالجين، مع التحقق من بصمتي الأرشيفين الرسميين قبل التغليف وإرفاق الترخيص. المستخدم النهائي لا يحتاج SDK أو Node منفصلًا.
- بيانات المستخدم خارج مجلد التطبيق. ملفات شهادة المعلم وهوية الطالب داخل مجلد خاص بالمستخدم، مع صلاحيات700 للمجلد و600 للملفات الحساسة.
- إنهاء التطبيق يوقف عملية Node التي شغّلها فقط؛ لا إضافة تلقائية إلى بدء التشغيل أو LaunchDaemon، ولا تعديل إعدادات جدار ناري أو Gatekeeper أو اعتماد أجهزة تلقائي.

## الحزم ومسار البناء

ينشئ `bash macos/build.sh <empty-output-directory>` على macOS مع أدوات Xcode:

- FBS-Classroom-Teacher-M175-macOS-Universal-PREVIEW.pkg
- FBS-Classroom-Student-M175-macOS-Universal-PREVIEW.pkg
- FBS-Classroom-Teacher-M175-macOS-Universal-PREVIEW.dmg
- FBS-Classroom-Student-M175-macOS-Universal-PREVIEW.dmg

PKG يضع التطبيق في Applications؛ DMG يتيح سحب التطبيق إلى Applications. اختر طريقة واحدة لكل تطبيق. تنسخ الحزم التطبيق فقط ولا تحتوي سكربتات تثبيت أو إزالة تغير إعدادات النظام. بيانات Keychain وApplication Support تبقى بعد إزالة التطبيق.

يبني GitHub Actions على فرع `build/m175-macos` دون تعديل main. لا تصبح أسماء الحزم أعلاه دليلًا على إنتاجها إلا بعد نجاح مهمة macOS وظهور الملفات الفعلية وتقرير التحقق. أي فشل تجميع أو تغليف يُعرض كما هو ولا يُعد نجاحًا.

## التحقق والحدود

يُعد المسار اختبارات إعداد Swift، وتجميعًا للمعالجين، وفحص بنية الحزمة وتشغيل Node المضمّن دون قراءة Keychain، وفك PKG ومطابقة بصمات كل ملفات التطبيق، وفحص DMG. هذه فحوص بناء وحزم، وليست تجربة تفاعلية على جهاز iMac.

التوقيع المستخدم Ad-hoc لفحص سلامة الحزمة المحلية؛ ليس توقيع Developer ID موثوقًا للتوزيع، ولا توجد Notarization. قد تمنع حماية macOS فتح نسخة تجريبية من الإنترنت. لا تُعطل الحماية العامة لتجاوز ذلك؛ يتطلب الإصدار الرسمي شهادة Apple Developer وتوثيق التطبيق.

لم يُختبر حتى الآن Keychain تفاعليًا أو نوافذ AppKit أو التقاط سطح مكتب Mac أو الاتصال بين جهازي Mac، ولا بين Windows وMac على شبكة فعلية. نُفذ تثبيت PKG وإزالته وفحص التطبيق المثبت فعليًا على مشغّل Mac Intel معزول؛ لا يمثل ذلك تجربة تفاعلية على جهاز المستخدم. نواة TLS والرسائل ونقل JPEG مشتركة مع النسخة السابقة، لكن ذلك لا يثبت تشغيل واجهات Mac.

نسخة Windows المنشورة الأخيرة M174 تبقى محفوظة. القفل وتوزيع الملفات والتحكم الفعلي وإدارة المعامل الدائمة والمطابقة الكاملة للتصميم ليست مكتملة. نسخة Mac في مرحلة التطوير، وليست إصدارًا نهائيًا معتمدًا.

## إعادة البناء

أُعد دعم فروع إعادة البناء التي تبدأ بـbuild/m175-macos- للمراجعة المحلية. وافق المستخدم صراحة على رفع المصدر وتمكين البناء والنشر التجريبي من هذه الفروع. لا يعد إعداد الملف محليًا نجاحًا للبناء أو نشرًا للحزم.
