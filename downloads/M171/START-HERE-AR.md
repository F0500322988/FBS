# M171 — مثبّت المعلم ومثبّت الطالب بصيغة EXE

أُنتج ملفا تثبيت فعليان لتطبيق Windows x64 بالإصدار `0.170.0-preview`:

- `FBS-Classroom-Teacher-M170-Setup-PREVIEW.exe`
- `FBS-Classroom-Student-M170-Setup-PREVIEW.exe`

استُخدم مترجم NSIS الأصلي على Linux من حزم Debian الموقعة. أدوات Inno وWine التي جرى تشخيصها سابقًا لم تُستخدم لإنتاج هذين الملفين.

## ما يفعله المثبّت

- واجهة تثبيت عربية، واختصار للبرنامج واختصار للإزالة في قائمة ابدأ.
- المعلم يُثبّت في Program Files بصلاحية إدارية، والطالب في مجلد برامج المستخدم الحالي دون طلب ترقية صلاحيات.
- Node.js و.NET مضمنان؛ لا يحتاج المستخدم إلى تثبيت SDK أو OpenSSL لتشغيل البرنامج.
- إعدادات DPAPI وبيانات المعلم والطالب مخزنة خارج مجلد البرنامج وتبقى محفوظة عند الإزالة.
- يرفض مجلد تثبيت غير فارغ. لتحديث النسخة التجريبية تزال النسخة السابقة أولًا.
- الإزالة تحذف قائمة الملفات المملوكة لهذا البناء فقط، ولا تستخدم الحذف التكراري لمجلد البرنامج؛ الملفات الإضافية غير المعروفة تبقى محفوظة.
- إذا تعذر حذف ملف مملوك، تتوقف الإزالة مع فشل وتبقى بيانات الإزالة لإعادة المحاولة بعد إغلاق التطبيق.
- لا تشغيل تلقائي بعد التثبيت، ولا إضافة تلقائية لبدء التشغيل، ولا تعديل جدار ناري أو اعتماد أجهزة.
- فحص CRC داخل المثبّت مفروض، وتُرفق إشعارات تراخيص التبعيات.

## التحقق المنفذ

- نجاح تجميع المثبّتين، ثم نجاح إعادة البناء من سكربت المصدر.
- نجاح فك الأرشيف الداخلي باستخدام 7-Zip، ومطابقة SHA-256 والحجم لـ42 ملف برنامج في حزمة المعلم و41 ملفًا في حزمة الطالب.
- رفض الملفات الداخلية غير المتوقعة؛ سُمح فقط بموارد NSIS القياسية التي أضافها المترجم.
- التحقق من رؤوس PE ومن أن التطبيق المضمّن AMD64. المثبّت نفسه يستخدم bootstrap من نوع x86 Unicode لتطبيق Windows x64.
- JavaScript: 1436 ناجحًا، دون فشل أو تخطٍّ. فحوص .NET الأخيرة للإعداد وTLS: 48 ناجحًا، وNativeGate: 80 ناجحًا.

## ما لم يُنفذ

التثبيت والإزالة وتشغيل الواجهات وDPAPI على Windows فعلي، والاتصال بين جهازين، والتوقيع الرقمي. الملفان جاهزان للتثبيت التجريبي، وليسا إصدارًا نهائيًا معتمدًا. تقرير المحتويات والبصمات هو `FBS-Classroom-M171-Installer-Verification.json`.

## التجربة على جهاز Windows واحد

1. شغّل ملف المعلم أو الطالب المناسب واتبع المعالج. أغلق التطبيقين قبل الإزالة.
2. افتح المعلم من قائمة ابدأ، واختر «لا» إذا طُرح فحص مسؤول المعمل لمتابعة اللوحة. أكمل الإعداد الأولي وأبقِ نافذة بيانات الاتصال مفتوحة.
3. افتح الطالب وأدخل مفتاح المعمل نفسه. للتجربة على الجهاز نفسه اختر الاتصال اليدوي بعنوان `127.0.0.1` والمنفذ `4180` وبصمة المعلم المعروضة.
4. سجّل الدخول في لوحة المعلم وراجع الجهاز ثم اعتمده.

التحكم والبث والقفل والرسائل وتوزيع الملفات ونسخة macOS لم تكتمل. الصورة المرسلة مرجع واجهة معتمد للعمل اللاحق وليست الواجهة الحالية المكتملة. لم تُنشر البيئة أو تُرفع الملفات إلى GitHub.
