# M186 — مفتاح المعمل وكلمة مرور المعلم من 3 إلى 8 أرقام

المصدر: b68142a، الفرع build/m186-pin-r2.

- الحد الأدنى 3 أرقام، والحد الأقصى 8، لكل من مفتاح المعمل وكلمة مرور المعلم في الإعداد الجديد على Windows وmacOS.
- رفض الأحرف والمسافات ومحارف نهاية السطر. الحفاظ على الصفر الأول وتطبيع الأرقام العربية والفارسية إلى ASCII.
- تحديث مدققات JavaScript وC# وSwift وPowerShell والتخزين المحمي واستيراد ملفات تهيئة الطلاب. خُفّض الحد الأدنى لحمولة مفتاح DPAPI إلى 6 بايت، مع استمرار فحص المحتوى الرقمي والتوافق القديم.
- الإعدادات القديمة لا تُختصر أو تتغير تلقائيًا؛ تبقى قابلة للتحميل حفاظًا على اتصال المعمل.

## التحقق

نجحت المراحل الأربع لتشغيل البناء النهائي. نُشرت الحزم وتحققت روابط EXE وPKG الأربع برمز HTTP 200.

- محليًا: 67 فحص .NET وإعداد وTLS؛ و5 اختبارات JavaScript تشمل اتصالًا حقيقيًا محليًا بمفاتيح 3 و8 أرقام وتسجيل دخول بالأرقام العربية.
- GitHub: نجحت مجموعة JavaScript الكاملة ومشاريع Windows الأصلية العشرة.
- Windows: نجح تثبيت المعلم والطالب والتحقق من 528 و524 ملفًا، وتشغيل 39 فحص أداة تهيئة في كل نسخة باستخدام مفتاح اختبار من 3 أرقام، ثم الإزالة مع حفظ ملف مجهول تجريبي.
- حزم Mac: نجح بناء تطبيقي Universal والتحقق من PKG وDMG وتثبيتهما وإزالتهما على جهاز CI من نوع Intel.
- Mac helper: بناء Universal و41 فحص إعداد Swift و41 فحص تهيئة وKeychain على Intel. مفاتيح الاختبار ليست بيانات معمل المستخدم.
