# M181 — التحكم بالمؤشر ولوحة المفاتيح وقفل الحساب

نفّذت هذه المرحلة أوامر النقر الأيسر والأيمن والمزدوج، والتمرير، والسحب والإفلات النسبي، والمفاتيح والاختصارات. تبقى موافقة الطالب المحلية، ومشاركة الشاشة الكاملة الحديثة، وبصمة المعلم المثبتة، وزر الإيقاف الظاهر شروطًا للتنفيذ. لا تُفعّل الأوامر الجديدة على طالب قديم دون قدرة الإصدار الثاني.

أُعيد ترتيب واجهة المعلم: شريط إجراءات مباشر، وشعار قبعة التخرج، وألوان زرقاء، وتقليل المسافات، وعرض الصورة بجانب أدوات التحكم على الشاشات الواسعة، وترتيبها عموديًا على الهاتف. حُدثت ألوان تطبيق الطالب وزر إيقافه الرئيسي لإيقاف التحكم الحالي أيضًا. الصورة المرفقة من اختبار آلي ببيانات اختبار؛ ليست صورة لأجهزتك.

## قفل حساب النظام

طلب القفل يوقف جلسة التحكم أولًا، ثم يعرض تأكيدًا مستقلًا على جهاز الطالب. Windows يستخدم `LockWorkStation`، وMac يرسل اختصار قفل الشاشة الرسمي `Control+Command+Q` بعد إذن Accessibility والتأكيد المحلي. لا توجد وظيفة لفتح القفل عن بُعد. كلمة مرور الحساب تبقى محلية.

لا تعلن الواجهة أن الحساب قُفل لمجرد إرسال الطلب. نجاح API أو إرسال أحداث النظام لا يثبت اكتمال القفل. يجب مشاهدة شاشة قفل النظام وفتحها بكلمة مرور الحساب ضمن اختبار الأجهزة الفعلية. حجب العرض القديم ما زال وظيفة منفصلة، وليس قفل حساب النظام.

## نتائج البرامج مقابل نتائج الأجهزة

نجح 1502 اختبار JavaScript، ونجح اختبار Chromium الذي يغطي النقر والتمرير والسحب والاختصارات وتأكيد طلب القفل، إلى جانب رجوع وظائف الرسائل والملفات والبث وتنظيم المعمل. نجحت اختبارات النقل الحقيقي عبر TLS ورفض الأوامر دون موافقة أو رمز مالك أو شاشة حديثة.

تقرير JSON النهائي وروابط CI في مجلد التسليم يحددان نتيجة التثبيت والبناء واختبارات النظام الأصلية بدقة. اختبارات Windows تستهدف نافذة يملكها الاختبار فقط. لا يتم قفل Runner لاختلاق إثبات لقفل جهاز المستخدم.

أبلغ المستخدم عن توفر Windows وMac. لا توجد جلسة وصول مباشرة إلى هذين الجهازين من المحادثة، ولم تصل نتائج تشغيل حزمة الاختبار عليهما بعد. لذلك يبقى القفل الفعلي والتحكم عبر الشبكة بين الجهازين وأذونات Mac وقبول المستخدم غير مختبرة على أجهزته. لا تُعد الحزمة شهادة لاجتياز هذه الاختبارات.

## إخفاقات البناء التي ظهرت

- فشل تشغيل سابق لاختبارات JavaScript على Mac Intel قبل التغليف؛ لم تعرض واجهة GitHub سببًا تفصيليًا كافيًا، فلا ننسبه إلى سبب مؤكد. التشغيلات اللاحقة موثقة في CI.
- فشل تغليف DMG على Apple Silicon برسالة `No space left on device` أثناء نسخ Node داخل الصورة. أضيف احتياطي صريح لمساحة نظام ملفات الصورة بدل الاعتماد على التقدير التلقائي؛ يلزم نجاح فحوص الحزمة النهائية لإثبات المعالجة.

## اختبار Windows وMac المتوفرين

نزّل `FBS-Classroom-M181-Device-Tests.zip` واقرأ `M181-DEVICE-TESTS-AR.md`. فحص Windows يطابق ملفات التثبيت مع بصماتها ويشغّل Node المضمّن ويتحقق من المنفذ المحلي. فحص Mac يراجع الإصدار والتوقيع وسلامة الحزمة والتشغيل المحلي؛ لا يمنح أذونات النظام تلقائيًا. الاختبارات اليدوية تبقى `not-run` حتى تُنفّذ، وتُسجّل نتائجها بوصفها نتائج أبلغ عنها المستخدم.

لا تجمع الحزمة كلمات مرور أو مفاتيح المعمل أو المفاتيح الخاصة أو ملفات الهوية أو صور الشاشة. أرسل تقارير JSON ونتائج القائمة اليدوية فقط.

## حدود الإصدار

التحكم هنا بأوامر المؤشر ولوحة المفاتيح ضمن صلاحيات المستخدم، مع حركة وسحب نسبيين. لا يتضمن تجاوز شاشة الدخول أو التحكم في سطح المكتب المحمي أو اتصالًا غير مراقب. مدة الجلسة دقيقتان كحد أقصى وتحتاج موافقة جديدة بعدها. التصميم تنفيذ عملي مستوحى من المرجع، وليس مطابقة بكسلية مثبتة للصورة الأصلية.

المثبّتات تجريبية غير موقّعة على Windows، وMac بتوقيع Ad-hoc دون Developer ID أو Notarization. لا يمكن وصف البرنامج بأنه نسخة نهائية معتمدة قبل اجتياز اختبار الجهازين الفعليين، واختبار الأداء بالعدد المستهدف، والتوقيع اللازم للتوزيع.

حقل `remoteControl:false` القديم يخص مسار `/control` التاريخي، ولا يعني تعطيل إدخال `/assist` الجديد. قدرات M181 معلنة في `consentedDesktopControl` و`localConfirmedSystemLock`، ولكل طالب تفاوض قدرة مستقل. لا تستخدم تقارير المعاينة القديمة بوصفها إثباتًا لهذه المرحلة.

- [Mac Intel النهائي](https://github.com/F0500322988/FBS/actions/runs/41987727361): نجح البناء والتثبيت والإزالة والتشغيل المحلي والتحقق من PKG وDMG، ونُشرت [الحزم Universal النهائية](https://github.com/F0500322988/FBS/releases/tag/m181-macos-preview-34-1).
- [Mac Apple Silicon](https://github.com/F0500322988/FBS/actions/runs/41986698311): نجحت الفحوص نفسها، ونُشرت الحزم Universal في `m181-macos-arm-preview-12-1`.

الحزم الحالية جاهزة للتجربة على الجهازين المتوفرين لديك. يبقى اختبار التحكم والقفل الفعلي عليهما غير منفذ حتى استلام نتائجهما.
