# نتائج المثبّتات المحدثة مع أدوات M184

أصبحت أدوات التهيئة جزءًا من مثبّتَي المعلم والطالب على Windows وMac. على Windows توجد اختصارات إعداد المعلم واختيار ملفه من USB في قائمة ابدأ. على Mac يوجد زر يفتح مجلد الأدوات من نافذة الإعداد، ومعه مستورد ملف المعلم. لا تحتاج تنزيل حزمة التهيئة منفصلة بعد تثبيت هذه النسخ.

تحتوي الملفات العامة أدوات M184 المثبتة بالبصمات فقط، دون ملف معمل حقيقي. يُنشأ ملف المعلم الخاص محليًا من إعداد حسابه المحمي وشهادته، ويحتاج حفظًا ونقلًا إداريًا لأنه يتضمن مفتاح المعمل مقروءًا للنقل. لا يتضمن كلمة مرور المعلم أو مفتاح شهادة TLS الخاص أو هوية طالب آخر.

## الإصدار والتوافق

حزمة التثبيت المحدثة تحمل اسم M184، والتطبيق الأساسي يبقى 0.183.0 المتوافق مع أدوات التهيئة المختبرة. مراجعة ملف مثبّت Windows هي 0.183.184.0، ومراجعة تطبيق Mac الداخلية 0.183.184 مع نسخة PKG رقم 0.184.0. هذا يسمح بقراءة إعداد M183 الحالي دون تغيير صيغته أو استبدال إعداد معمل آخر.

نسخة Windows الأساسية أخذت من مثبّتَي M183 المعروفين بالبصمات، وتحقق كل ملف قبل إضافة الأدوات. حُققت أيضًا مطابقة ملفات JavaScript والواجهة للمصدر الحالي. أدوات التهيئة المدمجة مطابقة بايتًا للأدوات التي اجتازت اختبارات M184 الأصلية.

## Windows

[مسار البناء](https://github.com/F0500322988/FBS/actions/runs/42062857298) يستخدم NSIS على Linux ثم يفحص ملفات PE والمحتويات والبصمات. نُشرت الملفات في [إصدار Windows](https://github.com/F0500322988/FBS/releases/tag/m184-windows-integrated-verified-4-1).

[التحقق النهائي على Windows 2022](https://github.com/F0500322988/FBS/actions/runs/42071024333) يشمل عشرة مشاريع .NET بإجمالي 231 تحققًا، وتثبيت مثبّتَي المعلم والطالب، والتحقق من **610 ملفات مثبتة**، وتشغيل أداة M184 المضمّنة فعليًا مع **39 تحققًا لكل دور**، وتشغيل Node المرفق، وفحص صياغة مستورد الملف واختصارات قائمة ابدأ. الإزالة تحذف الملفات التابعة للمثبّت وتحافظ على الملف الخاص غير التابع له.

بصمة المعلم SHA256: `d18251992fd6b259396bae74433c32dd2b9ee146254cf3ccd629c06453321813`.

بصمة الطالب SHA256: `0b377940f39dbdedf4a99e78c7e8c706d8eff41ba320ec9403f43998f2c31dc8`.

نُزّل الملفان من الروابط العامة وتطابقت أحجامهما وبصماتهما. حجم كل منهما نحو 116 ميجابايت؛ النشر في Releases لأن الملف يتجاوز حد ملف Git العادي. تقارير البناء وحدها لا تعني تنفيذ المثبّت؛ تقرير Windows-integrated-installer-smoke.json هو دليل مرحلة التثبيت اللاحقة.

## macOS / iMac

نجح [تشغيل Intel](https://github.com/F0500322988/FBS/actions/runs/42056932212)، ونُشرت حزم المعلم والطالب بصيغتي PKG وDMG في [إصدار Mac Universal](https://github.com/F0500322988/FBS/releases/tag/m184-macos-preview-47-1). الحزم تتطلب macOS 13 أو أحدث، وتتضمن معماريتي x86_64 وarm64 المتحقق منهما باستخدام lipo.

اجتازت **1513 اختبار JavaScript**، ونجح البناء والتوقيع ad-hoc، والتحقق من حمولة PKG وصورة DMG، والتثبيت والإزالة في جهاز بناء معزول وفحص التشغيل المحلي Loopback. اجتازت أداة التهيئة المضمّنة **41 تحققًا** بمخزن Keychain اختبار مؤقت، منها قارئ مستقل يقرأ الإعداد المصرح له دون حوار مصادقة في الاختبار.

نُزّلت حزم PKG/DMG الأربع وتحققت SHA256 وصيغتا xar/koly. حُققت **58 بصمة ملف لكل تطبيق** في بيانات حمولة التثبيت، وبصمتا أداتَي Windows وMac مطابقتان للحزمة الأصلية، و41 بصمة لملفات التشغيل والواجهة لكل دور مطابقة للمصدر.

لم يبدأ فحص تشغيل ARM المستقل للحزم الجديدة: تعذر على GitHub توفير Runner في ثلاث محاولات، منها مجموعتا macOS 26 وmacOS 15. سجل [المحاولة الأخيرة](https://github.com/F0500322988/FBS/actions/runs/42063562011) يذكر Internal server error وnot acquired قبل أي اختبار. لا يُسجّل هذا نجاحًا أو فشلًا لتشغيل البرنامج على ARM. الملف Universal بُني وتحقق معماريًا على Intel؛ التجربة الفعلية على Apple Silicon تبقى مطلوبة.

## ما لم يُختبر

لم تُثبت هذه الملفات على أجهزة المستخدم أو في المعملين من البيئة السحابية. اختيار ملف USB بالنوافذ الأصلية، والضغط على زر الأدوات الجديد داخل تطبيق Mac الكامل، وأذونات TCC وKeychain الفعلية وسياسات المؤسسة لم تُختبر تلقائيًا على أجهزتك. اختبارات WinForms/AppKit السابقة تخص نوافذ اختبار مملوكة؛ لا تُعد تجربة معمل.

Windows غير موقع، وMac بتوقيع ad-hoc دون Developer ID أو notarization. الحزم تجريبية؛ اختبر طالبًا واحدًا أولًا، ثم تحقق من الاتصال والاعتماد والبث وملء الشاشة والتحكم والطاقة قبل تعميمها. الإيقاظ من إيقاف كامل على Mac يظل مرتبطًا بالعتاد والشبكة. لا تفتح المثبّتات الجدار الناري ولا تمنح أذونات النظام أو الاعتماد تلقائيًا.

على Windows أغلق التطبيق وأزل النسخة السابقة بالطريقة المعتادة قبل التثبيت. لا تُحذف بيانات الحساب المحمية أو الهوية الموجودة خارج مجلد التطبيق. احتفظ بالملفات الخاصة الباقية بدل حذفها لتجاوز رفض مجلد تثبيت غير فارغ. على Mac أغلق التطبيق قبل تحديث PKG أو استبداله من DMG، وقد يلزم السماح مجددًا بالوصول إلى Keychain بعد تحديث التوقيع التجريبي.
