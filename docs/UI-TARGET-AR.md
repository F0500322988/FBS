# مرجع الواجهة الذي اعتمده المستخدم

أرسل المستخدم صورة تضم لوحة المعلم وشبكة شاشات الطلاب ومشاركة شاشة المعلم وإعدادات المعامل ونافذة الطالب، وطلب أن تكون الواجهة النهائية وفقها.

- هوية FBS Classroom بألوان كحلية وزرقاء وتدرجات خفيفة وشعار قبعة التخرج.
- تخطيط عربي باتجاه RTL وقائمة جانبية ثابتة وأيقونات واضحة.
- بطاقات الأجهزة بأسماء المحطات وحالة الاتصال، وشبكة شاشات قابلة لتغيير كثافتها وتكبيرها.
- شريط إجراءات واضح للوظائف المكتملة، وحالة معلنة للوظائف التي لا تزال غير متاحة.
- إعدادات للمعامل والمجموعات وصلاحيات المعلم وخيارات الأمان.
- نافذة طالب مختصرة تبين اسم الجهاز والمعمل وحالة اتصال موثقة وزر الإيقاف المناسب للجلسة.

عدادات الأجهزة وحالة الاتصال والصور تأتي من البيانات الفعلية أو توسم صراحة بأنها تجريبية. الصور في مرجع التصميم ليست دليلًا على تنفيذ بث الشاشة أو التحكم أو القفل أو نقل الملفات.

الواجهة الحالية ليست مطابقة كاملة للصورة. مرحلة M171 تختص بإنتاج المثبّتات؛ مطابقة الواجهة وتنفيذ الوظائف المتبقية أعمال لاحقة.

مرحلة M172 أضافت عرض القائمة والتحكم بحجم البطاقات والحالات الخالية وتصحيح مؤشرات الاتصال وإزالة الصور القديمة؛ تظل المطابقة الكاملة للنوافذ الأصلية وميزات التشغيل الناقصة غير مكتملة.
