# نتيجة M180 — FBS Classroom

تضيف هذه المرحلة مساعدة محدودة لجهاز طالب واحد: تحريك نسبي للمؤشر وكتابة نص Unicode عادي، بموافقة الطالب وبعد تثبيت عنوان المعلم وبصمته ومشاركة الشاشة الكاملة. لا تدعم النقر أو الاختصارات أو Enter. التطبيق ما زال إصدارًا تجريبيًا، وليس النسخة النهائية الكاملة.

## ما اكتمل

- لوحة عربية لطلب المساعدة ومتابعة الصورة الحديثة وإرسال الأوامر المحدودة وإيقاف الجلسة.
- نافذة موافقة محلية في تطبيق الطالب على Windows وMac، مع إظهار عنوان المعلم وبصمته وزر إيقاف.
- انتهاء الموافقة بعد دقيقتين كحد أقصى، أو فقد تجديد الاتصال أو الصورة أو الصلاحيات أو مؤشر الإيقاف.
- رفض الأوامر القديمة والمكررة وصفحات المشاركة التابعة لعملية وكيل سابقة، وعدم استعادة التحكم من إعادة تحميل لوحة المعلم.
- استمرار وظائف الرسائل والملفات ومشاركة شاشة المعلم والمراقبة وتنظيم المعمل والمجموعات ومكتبة ملفات التنظيم.

## الاختبارات المنفذة

- JavaScript: نجح 1499 اختبارًا، دون فشل أو تخطٍّ في التشغيل النهائي. فشلت إعادة سابقة في مهلة اختبار الرسائل M173 أثناء ضغط NSIS؛ نجحت إعادة التشغيل دون تعديل كود التطبيق أو مهلة الاختبار. سبب الإخفاق الأول غير محسوم.
- Chromium: نجح اختبار الواجهة والمساعدة، مع رجوع وظائف المراحل السابقة وفحوص الهاتف.
- Windows: نجحت مشاريع .NET السبعة، بما مجموعُه 185 فحصًا، منها إدخال فعلي داخل نافذة نص يملكها الاختبار، وحركة مؤشر صغيرة، ونص عربي وEmoji، ورفض النص عند ضغط Shift.
- Windows: نجح التثبيت والإزالة الفعليان للمثبّتين على GitHub Runner، وفحص بصمات 584 ملفًا مثبتًا، وتشغيل Node المضمّن، والحفاظ على ملف لا يملكه المثبّت أثناء الإزالة.
- Mac: نجح البناء والتثبيت والإزالة والتشغيل المحلي والتحقق من PKG وDMG على Intel وApple Silicon. تم تنزيل حزم Intel الأربع والتحقق من SHA256 وصيغ الحزم.
- تم تنزيل مثبّتَي Windows من روابط GitHub العامة والتحقق من بصمتيهما.

اختبار TLS يثبت نقل الأوامر والموافقة، واختبار نافذة Windows يثبت الإدخال المحلي. لم يُختبر بعد مسار الشبكة إلى برنامج الطالب كاملًا في جلسة فعلية. لم يُختبر إرسال CGEvent الحقيقي على Mac بعد منح Accessibility، ولا واجهة Keychain أو أذونات تسجيل الشاشة على جهاز المستخدم.

## الملفات الرئيسية

`classroom-assistance.js`، و`server.js`، و`teacher-lan.js`، و`student-agent.js`، وواجهة `public`، وملفات `AssistanceController` و`AssistanceInput` و`AssistanceCommandGate` في Windows، و`macos/Sources/AssistanceController.swift`، واختبارات M180 وتهيئة البناء والتغليف والدليل العربي.

## ما يلزم للنسخة النهائية

استكمال التحكم الكامل والنقر والاختصارات وفق موافقة واضحة، وتحديد تنفيذ قفل حساب النظام الحقيقي، وإتمام مطابقة الواجهة المرجعية، واختبار البرنامج كاملًا بين أجهزة فعلية واختبار أداء المعمل، ثم توقيع Windows وDeveloper ID وتوثيق Apple لحزم Mac. حجب العرض الحالي طبقة داخل التطبيق وليس قفل حساب النظام. ملفات تنظيم المعمل لا تعزل مفاتيح الاتصال أو اعتماد الطلاب.

يمكن لجهاز Windows واحد إثبات التثبيت وبعض الوظائف المحلية فقط؛ لا يثبت تجربة شبكة بين المعلم والطالب أو تشغيل iMac.
